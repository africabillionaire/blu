# Bluzoft Digital Transformation Agency

This repository contains the implementation of Bluzoft's digital transformation platform.

## Repository Structure

```
bluzoft/
├── backend/           # Rust/Actix Web GraphQL service
├── docs/              # Documentation and skill modules references
│   ├── detail design/
│   ├── muller-brockmann-grid-systems/
│   └── ux-psychology-for-addictive-app/
├── frontend/          # Oracle Jet application (official_web directory)
│   └── official_web/
├── infra/             # Deployment, CI/CD configurations
└── BLUZOFT_IMPLEMENTATION_PLAN.md  # Detailed implementation plan
```

## Skill Modules

The following skill modules are referenced in the implementation plan and stored in the `docs/` directory:
- **detail design**: Principles for polished interactions and visual design
- **muller-brockmann-grid-systems**: Grid-based layout systems for timeless elegance
- **ux-psychology-for-addictive-app**: Ethical engagement and user psychology principles
